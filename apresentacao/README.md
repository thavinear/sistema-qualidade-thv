# SGQ SENAC — Apresentação e protótipo

Entrega isolada feita em HTML, CSS e JavaScript vanilla. Abra index.html diretamente no navegador. Não requer instalação, servidor, dependências ou conexão de rede. Use tela cheia (F11).

## Navegação
Use os botões inferiores ou as setas esquerda e direita. Os pontos levam diretamente às seções. No protótipo, selecione módulos no menu.

## Seções
Capa, visão geral, módulos, arquitetura, protótipo interativo, jornada, próximos passos e encerramento.

A demonstração usa dados mockados, manipuláveis durante a sessão, sem integração ou persistência. Os estilos seguem a paleta e geometria do frontend. As fontes são substituídas por opções locais para operação offline. A marca é tipográfica, não o logo oficial.

A documentação raiz cita H2, enquanto o Gradle declara PostgreSQL runtime; confirmar com a equipe. O roadmap é sugestão de discussão, não cronograma aprovado.
