# Sistema Integrado de Gestão da Qualidade — Frontend

Projeto frontend reorganizado a partir do arquivo original `sistema-qualidade.html`.

Instruções rápidas:

Instalar dependências e rodar servidor de desenvolvimento (Vite):

```bash
cd frontend
npm install
npm run dev
```

Observações:
- Mantive toda a lógica original (localStorage) e preservei handlers inline.
- Arquivo fonte original foi movido para esta nova estrutura e o JS foi convertido em módulo.
