          Estação

          Ajuda do SGQ SENAC

          Escolha uma ferramenta no menu e siga a orientação exibida no início de cada etapa. Cadastre problemas, investigue causas, planeje ações e acompanhe a execução no ciclo PDCA.

          1. Use as abas para alternar entre as ferramentas.
          2. Preencha os campos e use os botões de cada etapa para registrar informações.
          3. Os dados são salvos neste navegador. Use “Exportar dados” para guardar uma cópia.
          4. Use “Gerar PDF / Imprimir” e selecione “Salvar como PDF” na janela de impressão.

          Acessibilidade: navegue com Tab e Shift+Tab, acione botões com Enter ou Espaço e use Esc para fechar esta janela. Os controles têm foco visível e as mensagens são anunciadas pelo leitor de tela.
